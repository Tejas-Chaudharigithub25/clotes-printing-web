# PrintCrafter - Custom T-Shirt Printing Web Application

A full-featured responsive website built using pure **HTML5**, **CSS3**, and **JavaScript (ES6+)**.

## Features Included
1. **Interactive T-Shirt Customizer**:
   - Live color customization.
   - Artwork / Image upload & real-time canvas preview.
   - Dynamic price calculation based on quantity and fabric material.
2. **Demo Payment Gateway**:
   - Interactive payment modal simulating Credit Card / UPI transactions.
   - Instant order confirmation and receipt generation.
3. **Order Tracking**:
   - Customers can search using their unique Order ID or Email.
4. **Comprehensive Admin Portal**:
   - Admin Login (`admin` / `admin123`).
   - Order management table showing uploaded design, specs, and delivery address.
   - Status switcher (`Paid`, `Printing`, `Shipped`, `Delivered`).
   - Analytics Dashboard (Total Revenue, Active Printing Orders, Delivered items).
   - Data stored persistently in browser `localStorage`.

## How to Run
1. Unzip `tshirt_printing_app.zip`.
2. Open `index.html` in any web browser.
